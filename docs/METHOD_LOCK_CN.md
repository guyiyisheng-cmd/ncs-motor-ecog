# 本地接入的方法定义锁定

本说明在正式真实数据运行前保存。既有V02结果已查看，本轮为探索性资料的独立实现与复现，不是前瞻性预注册。科学问题保持为执行/想象时影像运动系统与局部功率、PAC如何对应，以及共同β特征与功率—PAC直接关系的范围。

M0为源β事件时程逐时点事件中位数的任务均值；M1为同一曲线任务均值减基线均值。M0估计原对数任务摘要，M1估计同尺度时间段差异，二者不是同一对象的胜负比较。任务[0,5]、基线[−2,0]，保留共同端点；不因符号改变定义。

PAC沿用已校正的逐窗、逐相位频率18箱平均幅度归一化。检查团队源代码后确认：有效缓存保存的是每事件任务窗MI中位数与基线窗MI中位数，轴为通道×幅度×相位×事件，已完成窗内汇总但未作事件条件汇总。新增显式 `source_window_medians` 接口，分别接收两个E×C×A×P数组；不补造窗级数据。随后任务减基线、逐格点事件中位、频率网格线性95百分位，与团队方法相同。原6任务窗和1基线窗计数来自缓存及源代码，仅为来源说明。

主要终点为每患者、动作内，同通道想象减执行的Δβ—ΔPAC Spearman ρ，分别保留M0/M1；患者摘要为全部五动作ρ中位数。原8×8网格与幅度70–90 Hz子网格均完整保留；同窗70–90 Hz功率的秩残差相关及OLS斜率为描述性辅助量。完整条件/差值表同时输出。没有目标ρ、显著性或方向选择。

不确定性使用既有实际1000组完整轮次索引，依据源事件键确认轮次编码后原样复用。每次重新聚合事件时程与PAC频率格点，范围固定现有患者、通道及动作，依赖轮次可交换性，非群体置信区间。患者是独立单位；通道、动作、事件、窗口不作为独立患者。

采集边界：复用源Morlet功率、预处理、注释事件时基与校正PAC数组，未冒称本次重新运行EDF/BOLD预处理。来源绝对事件时钟、较高幅度频段的采集通带、想象期同步肌电仍未获独立确认。70–90 Hz限制不能代替硬件验证。

CST分支从已有来源登记读取实际FA、左右掩膜及MD/RD/AD原件，分别保留仿射并检查原生网格，重算有限体素等权统计。连续任务影像/可靠位置不足时，空间配对保持缺失状态，不能以CST代替局部影像效应。

三类证据分别报告：人工软件测试验证公式与不变性；真实双运行及与有效源结果的逐键对照验证计算复现；临床效度仍取决于采集、定位、混杂和研究设计，前两类证据不构成方法优效或临床准确性证明。
