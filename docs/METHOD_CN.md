# NCS方法合同：先定义问题，再定义计算

## 1. 研究定位与实现范围

研究问题仍是胶质瘤执行/想象中局部功率、PAC及影像空间之间的关系。本包不因为“某方法已经发表”而把它当金标准，也不因为我们的结果不同就判错。比较必须先确认是否测量同一个对象。

本次实现分为：
1. **已有方法的明确表达与独立实现**：文稿已使用的MI、原β估计、层级配对、轮次重抽样。
2. **可检验的性质**：批量计算不依赖无关窗口；幅度单位改变不改变MI；同尺度基线差不受恒定dB偏移影响；重新排列输入不应改变对应身份。
3. **真实数据上的比较**：必须在本地接入后完成，结论不预先写入代码。

上述第1项不包装为新发明，第2项不是临床准确性的替代，第3项不由软件测试代替。创新可以来自更合理的估计对象、配对设计和可验证的误差处理，但“超过别人”的具体范围必须经实证明确。

## 2. 明确估计对象 {#explicit-estimands}

令 i 为患者，a 为动作，c 为通道，s 为条件，e 为事件，t 为时间，f 为频率格点。对源程序已定义的dB曲线 d(e,c,t)：

```text
m(i,a,c,s,t) = median over events e in (i,a,s) of d(e,c,t)
B_original(i,a,c,s) = mean over task t of m(i,a,c,s,t)
B_baseline(i,a,c,s) = mean over baseline t of m(i,a,c,s,t)
B_same_scale(i,a,c,s) = B_original - B_baseline
ΔB(i,a,c) = B(i,a,c,Imagine) - B(i,a,c,Move)
```

`B_original`回答源对数归一化任务摘要是多少；`B_same_scale`回答相同汇总曲线的任务期相对任务前改变多少。二者测量不同，不能因为一个符号不同就判另一算法有程序错误。若要讨论任务诱发变化，就应说明为什么选定的估计对象回答这一问题。

线性基线功率算术均值归一化后，平均比值可以为1，但一般 `mean(log r) != log(mean r)`。对正值，`mean(log r) <= log(mean r)`；后续事件中位数也不强制结果为0。因此原汇总曲线的负号并不自动等于同尺度下降。这是运算性质，不取决于某论文是否发表。

从定义直接得到：若同一通道/条件全部时间的dB曲线加常数k，则 `B_original`增加k，而 `B_same_scale`不变。这项性质由代码测试验证；不能据此声称同尺度定义解决了全部噪声、事件同步或生理解释问题。

本包默认保留文稿既有端点定义：任务[0,5]，基线[-2,0]，两者均含0采样点。若改变端点，须新方法配置与版本说明，不静默变更。

## 3. PAC：计算定义，而非显著性标签

对一个观察窗、一个相位频率：

```text
u_k = sum(A_t for t in phase-bin k) / number_of_samples_in_bin_k
p_k = u_k / sum_j u_j
MI = sum_k p_k * log(K * p_k) / log(K), K=18
```

所有u_k的计数只属于当前观察窗与相位频率。向同一次函数调用加入其他窗口，不能改变本窗的MI；正幅度单位变换 A→λA (λ>0) 也不改变p或MI。`core.py`提供向量实现和逐窗标量参照；批量不变性与比例不变性有独立测试。

该定义来自现有稿件采用的Tort型MI；不是本项目新发明的MI。未实施替代数据统计校准时，不将非零MI命名为显著耦合。空相位箱或全零幅度是未定义情形，本包不以补零掩盖。

条件摘要保留源顺序：

```text
D_e(c,A,P) = median_task_windows MI_e - median_baseline_windows MI_e
C_s(c,A,P) = median_events_in_condition D_e(c,A,P)
PAC_s(c) = quantile_0.95 over (A,P) of C_s(c,A,P)
ΔPAC(c) = PAC_Imagine(c) - PAC_Move(c)
```

频率百分位与事件中位数一般不交换。以单事件百分位再求条件中位数，会变成另一个估计对象；本包包含一个数值反例测试，避免“相同名称但不同算法”。窗数量由实际数组和元数据确认；不把旧6窗自动改为7窗。

## 4. 联合比较与重复测量

对每个患者、每个动作，跨全部对应通道计算 `rho(rank(ΔB),rank(ΔPAC))`。每患者取其动作特异系数的中位数。只有全部预定动作系数有定义时才产生该患者中位数；不静默删掉常数/缺项动作以得到更有利的系数。

普通斜率为描述量；秩残差相关可选控制实际提供的同窗70–90 Hz功率。它们不能证明独立机制或信息增益。若需要回答预测增益，必须另有明确预测任务与不泄漏评估，而不是把低相关自动叫作额外信息。本轮不自动扩大到新的网络或解码课题。

完整轮次共同抽样保留同一患者五动作、两条件及全通道结构。每次从事件时程和完整PAC格点重新计算，而非从已汇总的ρ抽样。由1000次抽样的2.5/97.5百分位构成**条件范围**：条件于这些患者、通道、动作和观测轮次，并依赖轮次可交换性。它不覆盖群体变异，也不纠正任务绝对时钟。

## 5. 方法评价怎么使人信服

论文中的“方法可信”分开落实：

|命题|本包已实现/需本地完成|
|---|---|
|公式与程序一致|MI标量对照、聚合顺序反例、显式端点等软件测试已实现|
|程序不受无关批次或单位影响|批次/比例/排列等性质测试已实现|
|同一数据可重现同一估计|命令行双运行比较已实现；临床数据须本地执行|
|定义比另一种更适合本研究|先说明不同估计对象及适用假设，再用同一资料作完整对照；不是预设优效|
|真实测量反映神经活动或临床功能|仍需实际采集、定位、混杂处理及设计证据，不能由CI绿灯推出|

测试中的已知调制/恒定幅度信号只用于验证公式实现，不等同于从原始临床信号滤波后的全部假阳性评估。尚未实现的检验不可写成通过。

若本地团队原方法与本包明确公式不同，先从代码和原设计说明差异属于“估计对象不同”“实现错误”还是“无法判定”，再一次性锁定本轮主分析配置。不能仅为匹配本包输出覆盖团队算法；也不能为恢复旧论文结论修改真实结果。

## 6. 影像不是装饰，缺失也不是零相关

保留结构与任务空间为研究组成部分。CST原生网格定量和可靠fMRI/位置对应是不同层级：前者不能充当后者。

空间配准可以开发或改进，但优化依据是解剖与几何的独立对应，而不是使电生理相关系数最大。仅头信息相等不能确认真实配准。当前代码只接受有来源证据键的配对表；这张表的真实性仍由原始定位与任务资料验证，不由布尔字段自动认证。
