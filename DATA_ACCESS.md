# Data access and public download scope

Public repository and release downloads contain software, input schemas and synthetic-test definitions only. They contain no real patient observations or clinical image assets. Synthetic arrays can be generated locally and are explicitly labelled artificial.

Raw recordings, original and derived clinical images, operative photographs, navigation records, identity links and real patient-derived numerical/display arrays remain outside this repository. Access to these materials requires applicable ethics, privacy, institutional and third-party permissions. Requests should be directed privately to the corresponding authors identified in the associated manuscript, specifying the intended use and requested input level. Do not post patient data or personal details in a public GitHub issue. This page does not guarantee access or replace an institutional approval procedure.

The author has stated that permission exists for some real derived data and will provide its exact file scope and basis. Those details and the applicable data license have not yet been provided. Consequently, no clinical dataset is released under MIT, no clinical download address is available here, and no data DOI has been assigned. A future data release would require its own explicit file inventory and license. Software access is independent of data access.
